# site — конвенции для агентов

Публичный статический сайт. Всё, что здесь появляется, читает интернет и индексируют поисковики.

## Обязательное

- Никаких секретов, токенов, внутренних адресов, имён приватных репозиториев и личных данных, которых владелец не собирался публиковать.
- Только статика: никакого серверного кода, никаких вызовов сторонних API из браузера, кроме аналитики, если владелец её попросил.
- Сборка обязана быть воспроизводимой: `npm ci && npm run build` с нуля даёт рабочий `dist/`.
- Контент — отдельно от вёрстки: тексты в `src/content/`, а не в разметке компонентов.

## Проверка перед коммитом

```bash
npm ci && npm run build
```

Деплой на Pages: пуш в `main`, workflow в `.github/workflows/` — единственный способ выкладки.
